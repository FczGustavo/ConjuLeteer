# Auditoria visual do corpus inglês

Executada em 03/09/2026 no navegador in-app, com a pré-visualização completa de **3.313 questões estudáveis** (Inglês público + Inglês Preview).

| Verificação | Resultado |
| --- | ---: |
| Enunciados ausentes | 0 |
| Questões com 4/5 alternativas inválidas | 0 |
| Créditos ausentes | 0 |
| Texto não justificado | 0 |
| Recortes sem asset, fonte ou legenda | 0 |
| Blocos de apoio renderizados | 980 |
| Títulos de apoio destacados e sem ponto terminal | 593 |
| Recortes visuais renderizados | 87 |

O carregamento das imagens é lazy-load para preservar fluidez. Os 87 descritores possuem URL de asset, hash, recorte e a legenda **“Recorte visual da questão”**; a decodificação foi confirmada para os recortes colocados no viewport e os demais foram validados por asset e URL.

Foram conferidos 54 links canônicos de bancas: 50 responderam HTTP 200 e 4 retornaram 403 por proteção anti-bot dos portais oficiais (não são links quebrados). Entre os 3.313 créditos exibidos, 3.148 têm portal oficial clicável; 165 bancas sem diretório oficial permanecem como crédito textual, sem href inventado.

Também foram corrigidos: a questão 19 de Numbers (enunciado separado do trecho citado), o título incorporado da EPCAR 47 e o conjunto EFOMM 2015 (questões 22–24), que agora compartilha o texto de apoio, exibe a manchete em destaque sem ponto terminal, separa a autoria e mantém o comando da questão no enunciado. O gate de qualidade passou.
